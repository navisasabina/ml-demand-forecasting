# 📈 Machine Learning Demand Forecasting using Apache Spark MLlib

An end-to-end machine learning project that predicts product demand using Apache Spark MLlib. This project demonstrates the complete data analytics workflow, from preprocessing and feature engineering to model training and evaluation, to support data-driven decision-making.

---

## 📖 Project Overview

The objective of this project is to develop a demand forecasting model using Apache Spark MLlib. By analyzing historical sales data, the model predicts future product demand, helping businesses optimize inventory planning and reduce stock shortages or overstock situations.
